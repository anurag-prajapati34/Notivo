# Notivo
Notivo is a **developer tool**. Developers who build apps (e-commerce, SaaS, food delivery etc.) connect to Notivo's API and use it to send email notifications to their users — without building the whole notification system themselves.

**Notivo handles:** Templates, delivery queues, retries on failure, delivery logs, scheduling.

**Developer handles:** Just calling Notivo's API with a template ID and recipient email.
